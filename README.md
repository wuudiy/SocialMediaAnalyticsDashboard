# Social Media Analytics Dashboard

## 1. Project Overview

Social Media Analytics Dashboard is a desktop application built with C++, Qt, and MySQL.  It is designed to help users manage, import, analyze, and export social media post data from multiple platforms.

This project supports user authentication, role-based permissions, post management, CSV import, statistical dashboards, report export, and operation logging.
